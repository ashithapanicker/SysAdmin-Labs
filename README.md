# System Admin Lab — Active Directory & Windows Server

A documented, hands-on record of Windows Server administration tasks performed 
in a live sysadmin role, covering:

- Promoting a Windows Server to a Domain Controller (AD DS installation & DCPromo)
- Designing and implementing an Organizational Unit (OU) structure
- Creating and managing test user accounts within the domain
- (add more as you go: GPOs, DNS/DHCP config, group policies, etc.)

Each task includes step-by-step notes, screenshots, and any issues encountered 
and resolved — intended as verifiable proof of practical AD/Windows Server skills 
referenced on my resume.

## Why this exists
This lab tracks real work done on the job (not simulated), so recruiters and 
hiring managers can see actual execution rather than just a bullet point.
